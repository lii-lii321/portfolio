llm-eval-kit 343 个离线测试

离线可跑的 RAG 检索与 LLM 应用评测工具库：从纯文本文档合成评测集，对比多路检索管线，LLM-as-judge 四维评分，badcase 三类归因，产出 Markdown + HTML 双报告。

  • demo 实测（seed=42）：Recall@10 0.9583 · MRR 0.9375 · NDCG@10 0.9430
  • 聚合指标附 bootstrap 95% 置信区间（百分位法，重采样 1000 次），固定 seed 完全可复现
  • 评测回归门禁 --fail-under：任一指标低于阈值退出码 1，可直接作 CI 合并卡点
  • 支持人工标注 JSONL 评测集与外部语料（--dataset / --corpus-dir），分级标注自动产出 Weighted NDCG@10
  • 大语料快速路径：倒排索引 BM25 在 2 万段语料实测查询 P50 0.6ms vs 23.4ms（约 40x，中频词元查询；打分口径与玩具版一致）

credit-risk-modeling 150 个测试

端到端信贷违约风险建模（问题 → 数据 → 实验 → 解释 → 部署）：自实现 WOE/IV 与 PSI，2 模型 × 3 不平衡策略实验矩阵，SHAP 可解释性，FastAPI 评分服务。

  • 独立测试集（n=200）：AUC 0.8013 · KS 0.5119 · Gini 0.6026
  • 概率校准（发现 → 修复 → 复测）：ECE 0.1420 → 0.0681，平均预测 PD 0.437 → 0.301（实际违约率 0.300）
  • 公平性审计（personal_status 分组）：demographic parity 差距 0.336，三档阈值敏感性实测 0.336 → 0.389 → 0.222（差距非单调收窄），如实记录不作粉饰
